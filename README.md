## 🧪 Research & Projects

| Project | What it does | Stack |
|---|---|---|
| **Few-Shot Object Detection: Augmentation Study** · [augmix](https://github.com/velnmurugan/augmix) | Evaluated AugMix + JSD consistency loss across CNN, ViT, Detectron and YOLO models on a custom industrial tool dataset; analysed where classical detectors overtake few-shot models | PyTorch, Detectron2, YOLO |
| **3D Hand Pose for Assembly Feedback** *(Fraunhofer IPA)* | Multi-camera 3D hand keypoints, DTW-based motion comparison, real-time 3D hand meshes (HaMeR, WiLoR) | OpenPose, PyTorch |
| **[FPM](https://github.com/velnmurugan/FPM)** | Replaced Fourier ptychographic microscopy reconstruction with a physics-informed, complex-valued U-Net | PyTorch, GPU cluster |
| **[Bayesian Climate Reconstruction](https://github.com/velnmurugan/bayesian-climate-reconstruction-challenge)** | Ill-posed inverse heat problem: RBF basis, MAP estimate, Laplace approximation, evidence-based hyperparameter selection | NumPy, SciPy |
| **[Biomolecule Quantum Kernels](https://github.com/velnmurugan/Bimolecule_quantum_kernel)** | Predicting excitonic coupling energies with kernel ridge regression on Coulomb matrices, compared against quantum kernels | scikit-learn, PennyLane |
| **[Image Denoising](https://github.com/velnmurugan/Image-denoising)** | Self-supervised microscopy denoising (Noise2Void) | PyTorch |
| **ECG Digitisation** | Scanned ECG strips → calibrated time-series signals via image and signal processing | OpenCV, NumPy |
